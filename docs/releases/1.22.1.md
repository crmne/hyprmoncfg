# hyprmoncfg 1.22.1

A security fix: a display with a crafted name could make the daemon run commands as you. Update now if you use a classic `hyprland.conf` with workspace planning turned on. Install from the AUR or download a package below. This release works with [panel 2.7.0](https://github.com/crmne/omarchy-hyprmoncfg/releases/tag/v2.7.0) for Omarchy; the panel doesn't need an update.

## Fixed

- **A display can no longer inject Hyprland commands through its name.** The daemon sends workspace rules to Hyprland as one `hyprctl --batch` call, and those rules name each display by the description it reports about itself. hyprctl treats every `;` in that call as the start of a new command. So a monitor, dock or dongle whose description contained `;` could add commands of its own, including `dispatch exec`, and the daemon applies layouts by itself when a display is plugged in, the lid moves or the computer wakes. hyprmoncfg now refuses any batch command that contains `;` or a line break. A display whose description has one is named by its connector, such as `DP-3`, so its layout and workspaces still apply. See advisory [GHSA-793j-vprf-x26g](https://github.com/crmne/hyprmoncfg/security/advisories/GHSA-793j-vprf-x26g). Reported by @larrynz.

  **Who was affected:** setups using a classic `hyprland.conf` with workspace planning on in the applied profile, where someone could connect a display with a crafted description. Hyprland's Lua config, used by Omarchy 4, rejects the affected command, so those setups weren't exposed to this attack.

## Upgrading

Update both `hyprmoncfg` and `hyprmoncfgd`, then restart the service:

```sh
systemctl --user restart hyprmoncfgd.service
```

Nothing else changed since 1.22.0. The IPC protocol is still version 1.

## What's tested

- **Automated tests** cover a hostile description with ` ; `, a bare `;` and a line break: the batch is refused before hyprctl runs, a live apply names the display by its connector, and a revert skips a rule it can't replay safely.
- **On Hyprland 0.56.2:** `hyprctl --batch` was confirmed to split on a bare `;`, using a harmless command.
- **Not tried:** a real display with a crafted EDID.
