# 1.19.0 release evidence, 2026-09-24

## Automated validation

Before the release commit: `go mod tidy` with unchanged go.mod/go.sum,
`go test ./...`, `go vet ./...`, both command builds, and race tests for
`internal/hypr`, `internal/daemon`, `internal/ipc`, and `internal/tui` passed.
Whitespace checks passed. Companion panel validation passed 121 Node tests,
21 Qt tests, qmllint, and plugin validation.

## Screenshot provenance

The current TUI screenshot gallery was captured from the actual renderer at
1924x1084 pixels in light and dark Ghostty themes. The Layout, Workspaces,
Profiles, and Save profile views were visually reviewed. A read-only synthetic
IPC endpoint and compositor shim served data generated by
`go run ./scripts/capture-fixture NEW_DIRECTORY`, using the production status
and editor builders. The fixture refuses an existing destination. The endpoint
and shim rejected mutations; runtime/config paths were isolated from the user.
No layout was applied or profile saved to capture the images.

The first capture pass was rejected: advertised mode strings lacked Hyprland's
canonical refresh formatting and incorrectly showed an Unsupported mode warning.
The fixture now uses `hypr.FormatMode`. The final pass also forces only its
capture windows opaque so unrelated desktop content cannot show through.
The capture script targets the current Workspaces/Profiles keys (2/3).

The older demo video is retained and explicitly labeled historical. The README
and website hero now use the current Layout screenshot. Panel screenshot
provenance and reviewed sizes are recorded in the companion repository's
`design/implementation-status.md`.

## Live checks and limits

The installed main-build daemon was running and both physical displays reported
usable during release preparation. The maintainer previously reported successful
physical connect/disconnect behavior. That does not establish projector, lid,
suspend, failed-wake, or AC/battery transition acceptance. No physical topology
changes were made during screenshot capture. Synthetic captures and automated
regressions must not be presented as those missing checks.

See [release notes](1.19.0.md) for user-facing changes and known gaps, and
[reliability integration](../reliability-integration-2026-09-24.md) for the
contributor split and detailed regression evidence.
