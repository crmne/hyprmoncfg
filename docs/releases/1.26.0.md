# hyprmoncfg 1.26.0

Keep your workspace numbers and monitor assignments on Omarchy 4.5, and connect your workspace plan to the bar.

Download the [Linux x86-64 binaries](https://github.com/crmne/hyprmoncfg/releases/download/v1.26.0/hyprmoncfg_1.26.0_linux_amd64.tar.gz) or [Linux ARM64 binaries](https://github.com/crmne/hyprmoncfg/releases/download/v1.26.0/hyprmoncfg_1.26.0_linux_arm64.tar.gz), or install `hyprmoncfg-bin` from the AUR.

## New

- **Your workspace plan stays in control on Omarchy 4.5.** With the planner enabled, workspace numbers and move-window shortcuts use global destinations. Omarchy's competing per-monitor reassignment stands down through hyprmoncfg's existing generated Lua file. No additional include is needed. Choose Off to delegate workspace management again.
- **Assigned empty workspaces can appear in your bar.** The status stream now includes the active workspace plan. The optional [hyprmoncfg Workspaces picker](https://github.com/crmne/omarchy-hyprmoncfg-workspaces/releases/tag/v0.1.0) groups numbers by monitor, and [panel 2.11.0](https://github.com/crmne/omarchy-hyprmoncfg/releases/tag/v2.11.0) provides its Workspaces editor. Switching stays a direct Hyprland action.

## Fixed

- **Updated dependencies with security fixes.** Includes the Go system and text library updates from [#103](https://github.com/crmne/hyprmoncfg/pull/103) and [#104](https://github.com/crmne/hyprmoncfg/pull/104), by @renovate[bot].

## Upgrading

Update both `hyprmoncfg` and `hyprmoncfgd`, then restart `hyprmoncfgd.service`. Pair an enabled global workspace plan with hyprmoncfg Workspaces or [Global Workspaces](https://github.com/crmne/omarchy-global-workspaces/releases/tag/v0.1.1). Use the stock widget with planner Off for Omarchy's monitor-local model.

## Known limitations

- Omarchy 4.5's stock workspace widget still assumes monitor-local numbering. Changing ownership does not move or renumber existing windows.
- The Omarchy integration targets the workspace API introduced in 4.5 RC2. Plain Hyprland and older Omarchy installations without that API are unchanged.

## What's tested

The full Go suite, vet, CLI/daemon builds and race tests for status, rendering and IPC pass. Workspace handoff and status-plan behaviour have deterministic regression coverage. This release does not claim a new physical suspend/resume or hotplug test sweep.
