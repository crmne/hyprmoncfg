# hyprmoncfg 1.19.0: Plug in, settle in

A friendlier first connection, a clearer editor, and a daemon that stays responsive while a dock is still waking up. This release pairs with [Omarchy panel 2.4.0](https://github.com/crmne/omarchy-hyprmoncfg/releases/tag/v2.4.0).

![The refreshed layout editor](https://raw.githubusercontent.com/crmne/hyprmoncfg/v1.19.0/docs/assets/images/screenshots/layout-dark.png)

## New displays, without losing your saved setup

- Unfamiliar displays extend the current setup to the right, vertically centered against the adjacent display. The default picks the highest advertised resolution, then its highest refresh rate, with VRR off and conservative 8-bit SDR settings.
- The extended setup is temporary. Your saved profile stays intact, deliberate disabled displays remain off, and strict profiles can still opt out of unknown outputs.
- Sequential is the preferred new-plan strategy. Ambiguous single-display imports use groups of three; explicit saved strategies, workspace totals, and persistence are preserved. For example, a six-workspace plan with groups of three places 1–3 on the first display and 4–6 on the second.
- The closed-lid guard requires a usable external mode before turning off the internal panel. A connected but modeless external output is no longer sufficient.

## An editor that tells you what matters

- Consistent **1 Layout, 2 Workspaces, 3 Profiles** navigation. The old 2/3 shortcuts have swapped.
- Display cards show connector, model and whole-inch size, compact resolution@Hz, scale, position, and workspace IDs. No arbitrary display numbers or logical-size clutter.
- All six hardware details stay visible. Off and mirrored displays have selectable rows, and off displays expose an Enable action.
- Profiles have clearer columns, separate automatic-selection controls, visible actions, and an editable **Post-apply command** at the end of the details.
- Preview confirmation defaults to **30 seconds**, giving slower displays more time. Apply, Save, and Keys remain accessible at small terminal sizes.

![Profiles in the light theme](https://raw.githubusercontent.com/crmne/hyprmoncfg/v1.19.0/docs/assets/images/screenshots/profiles-light.png)

## A steadier daemon

- Failed automatic applies retry independently with capped backoff. Status distinguishes usable outputs from merely connected ones, and verification reports failures across outputs.
- Compositor reads have deadlines. Identity discovery skips unnecessary DRM probing and shares one bounded probe when identities are ambiguous.
- Coalesced background discovery and topology/wake generations keep stale results from replacing newer state. Clients can retain their last snapshot and retry a typed compositor-busy response.
- Workspace persistence supports **First per display** and **All assigned** in both editors; manual rules keep their individual flags.
- Optional `hyprmoncfgd --power-aware-refresh` adjusts internal-panel refresh for AC/battery transitions while retaining resolution and calibration. It is off by default.

## Upgrading and scope

Upgrade both `hyprmoncfg` and `hyprmoncfgd`, then restart the running user service:

```sh
systemctl --user restart hyprmoncfgd.service
```

Existing profiles are not migrated to Sequential. Change a saved plan explicitly if you prefer it. IPC remains protocol version 1; panel 2.4.0 requires backend 1.19.0.

Screenshots are actual TUI captures with synthetic profiles and displays. Automated regression and race checks cover discovery, preview ownership, retries, workspace intent, and UI interactions. The maintainer reported successful physical connect/disconnect testing; this is not a claim of complete projector, dock, lid, suspend, or power-transition testing.

All-displays-off startup rescue, failed-wake rescue and fallback modes remain incomplete. Layout reuse, shared preferences, notification routing, standalone TUI Identify, and a TUI profile context menu are not part of this release.

Thanks to @mapleroyal for the reliability work integrated from PR #61. Layout reuse remains under separate review.
